# AIエージェントの見本の置き場

この README は、見本（agent-template）と、あなたの置き場（my-agent）の両方に、同じものが入っています。

- いま **agent-template**（見本）を見ている人：下の「1. 自分の置き場を作る」へ
- いま **自分の my-agent** を見ている人：下の「2. 自分のことを入れる」へ

見本（agent-template）は読むだけです。ここには書き込みません。フォークも使いません。

## 1. 自分の置き場を作る

下のリンクを開きます。

[自分の非公開の置き場（my-agent）を作る](https://github.com/new?template_owner=nonakakenji&template_name=agent-template&name=my-agent&visibility=private)

開いたら、3つだけ見てください。

1. 持ち主が、自分の名前になっているか（会社や団体の名前になっていたら、自分の名前に変えます）
2. 名前が my-agent になっているか（すでにあるときは、my-agent-2 など別の名前にします）
3. Private（非公開）になっているか

合っていたら、緑の「Create repository」を1回押します。

リンクが効かないときは、このページの「Use this template」→「Create a new repository」で、名前を my-agent、Private を選んで作ります。

できたら、そのページ（自分の my-agent）は閉じないでください。

## 2. 自分のことを入れる

1. 新しいタブで claude.ai/code を開き、GitHub でつなぎます。GitHub のアプリを入れる画面では「Only select repositories」を選んで、**my-agent だけ**にします
2. my-agent を選んで、セッションを始めます（名前を変えた人は、自分でつけた名前の置き場です）
   - my-agent が出てこないとき（前に Claude と GitHub をつないだことがある人）：その画面の「Claude GitHub App をインストール」を押し、「Only select repositories」に my-agent を足して「Save」を押します。戻って、リポジトリの検索欄の右の更新ボタンを押します
3. 下の枠の一言をコピーボタンで写して、入力欄に貼って送ります（自分で打ってもかまいません）
4. エージェントが「まず、私の名前を決めてください」と聞いてきます。名前を決めたら、あなたのお名前・お仕事などを1つずつ聞いてくるので、答えます（5問だけでも先に進めます）
5. 終わったら、新しいセッションを my-agent で始めて、「あなたの名前は？」と聞きます。名前で答えたら完成です

### コピーする文

```
はじめまして！設定をお願いします
```

## GitHubがまだの人用（パソコンのフォルダで進める）

GitHub やクラウドにつながらないときは、パソコンの ai-renshu のフォルダで、Claude Code に次の文を貼ります。家で、1と2をやってから、同じ内容を my-agent に移します。

```
いま開いているフォルダに、CLAUDE.md という名前のファイルを新しく作ります。次のルールで進めてください。

・実名・住所・電話番号・パスワード・カード番号は、聞かないでください。私が書いてしまったら、保存しないで伏せてください
・私が書いていないことは、勝手に足さないでください

1. まず「私（エージェント）の名前を決めてください」と聞いてください。ひらがなかカタカナで4文字以内の案を3つ添えてください。そのあと、次の項目について、私に質問してください。質問は1回に1つだけ。私が答えてから次へ進みます。「パス」と言ったら飛ばします。最初に、★の5つ（呼び方／仕事・役割／時間をとられていること／任せてみたい仕事／してほしくないこと）を聞いてください
　項目：あなたの名前／呼び方★／仕事・役割★／仕事の相手／よくやる作業／時間をとられていること★／任せてみたい仕事★／使っている道具／補ってほしいこと／文章のトーン／してほしくないこと★／人が最後に見るもの
2. 答えをまとめた CLAUDE.md を見せてください。私が「OK」と言ったら、このフォルダに保存してください
```

## 注意

- ★の5問以外は、あとから足せます
- 「いま開いている置き場の名前は？」とエージェントに聞くと、どの置き場にいるか分かります
- 実名・住所・電話番号・パスワード・カード番号は、書かないでください
